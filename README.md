# Incident Handler's Journal

A running journal of security incident analyses completed as part of the
**Google Cybersecurity Certificate** program. Each entry documents a real-world
scenario using the 5 W's framework (Who, What, When, Where, Why) and reflects
on tools, techniques, and lessons learned.
